Pick the layer that matches your use case

They compose — start with the smallest and upgrade without rewriting your code.

🟢

One-shot fetch

Pull a worksheet into a pandas DataFrame, Spark DataFrame, CSV, JSON, or a single file.

Use for: ad-hoc analysis or small exports.

from nocoly_explorer import WorksheetExporter

df = WorksheetExporter().export(
    host="https://your-nocoly-host",
    worksheet_id="ws_123",
    output_type="dataframe",
)
🔵

Streaming export

Stream pages into partitioned Parquet without loading the whole worksheet into memory.

Use for: worksheets bigger than RAM, data-lake layouts.

from nocoly_explorer import (
    AsyncWorksheetClient, StreamingExporter,
    StreamingExportConfig, PartitionSpec,
)
🟣

Scheduled jobs

Submit an export to a small FastAPI service. Background Arq workers run it for you.

Use for: n8n, Airflow, cron, or any scheduler.

POST /jobs  →  {"job_id": "..."}
GET  /jobs/{id}  →  status + progress
POST /jobs/{id}/cancel
🟠

Schema discovery

Ask "what columns does this worksheet have and what types are they?" before exporting.

Use for: connecting to a new Nocoly app for the first time.

schema = client.get_worksheet_schema()
for col in schema.columns:
    print(f"{col.name}: {col.type}")

When to use which

Pick the smallest option that does the job.

If you need to…UseWhy
Look at a worksheet once in a notebook One-shot fetchSmallest setup; one import, one call
Save a worksheet to disk as Parquet for analysis Streaming exportHandles big worksheets without OOM
Run the same export every hour from cron / n8n / Airflow Scheduled jobsSubmit → poll; the worker does the heavy lifting
Build a pipeline that only pulls new rows each run Streaming + incrementalSaves bandwidth, avoids re-processing
Explore what columns a worksheet has before exporting Schema discoveryAvoids guessing; tells you types
Push exports directly into an S3 bucket Streaming + parquet_s3No local disk round-trip

Code examples

Six runnable scripts under examples/ cover each layer.

import os
from nocoly_explorer import WorksheetExporter, NocolyFilter

df = WorksheetExporter().export(
    host=os.environ["NOCOLY_HOST"],
    worksheet_id="ws_customers",
    filter_criteria=NocolyFilter.and_group([
        NocolyFilter.quick(Status="Active", _updatedAt__gt="2025-01-01"),
        NocolyFilter.or_group([
            NocolyFilter.quick(Region="HK"),
            NocolyFilter.quick(Region="SZ"),
        ]),
    ]),
    columns=["Name", "Region", "Status", "_updatedAt"],
    sorts=[{"field": "_updatedAt", "order": "DESC"}],
    page_size=500,
    max_pages=25,
)

print(df.head())
import asyncio
from nocoly_explorer import (
    AsyncWorksheetClient, StreamingExporter,
    StreamingExportConfig, ParquetExportOptions, PartitionSpec,
)

async def main():
    async with AsyncWorksheetClient(
        base_url=os.environ["NOCOLY_HOST"],
        auth_token=f"{os.environ['NOCOLY_APP_KEY']}:{os.environ['NOCOLY_APP_SIGN']}",
        worksheet_id="ws_orders",
        concurrency=8,
    ) as client:
        result = await StreamingExporter(
            client=client,
            config=StreamingExportConfig(
                output_dir="/mnt/datalake/nocoly/ws_orders",
                worksheet_id="ws_orders",
                options=ParquetExportOptions(row_group_bytes=128*1024*1024),
                partition=PartitionSpec(column="created_date", granularity="day"),
            ),
        ).stream_async(client, page_size=200)
        print(f"wrote {result.rows_written} rows")

asyncio.run(main())
from nocoly_explorer.client import WorksheetClient
from nocoly_explorer.auth import CredentialPair

client = WorksheetClient(
    host="https://your-nocoly-host",
    worksheet_id="ws_orders",
    credentials=CredentialPair(
        app_key=os.environ["NOCOLY_APP_KEY"],
        app_sign=os.environ["NOCOLY_APP_SIGN"],
    ),
)

schema = client.get_worksheet_schema()
print(schema.source)            # "api" or "inferred"
for col in schema.columns:
    print(f"  {col.name}: {col.type}  nullable={col.nullable}")

# Round-trip to JSON
open("ws_orders.schema.json", "w").write(schema.to_json())
import pyarrow.fs as pafs
from nocoly_explorer import (
    AsyncWorksheetClient, StreamingExporter,
    StreamingExportConfig, ParquetExportOptions, PartitionSpec,
)

fs, path = pafs.S3FileSystem.from_uri("s3://my-bucket/nocoly/")

async def run():
    async with AsyncWorksheetClient(...) as client:
        result = await StreamingExporter(
            client=client,
            config=StreamingExportConfig(
                filesystem=fs,
                output_dir=path + "ws_orders",
                worksheet_id="ws_orders",
                options=ParquetExportOptions(compression="snappy"),
                partition=PartitionSpec(column="region", granularity="day"),
            ),
        ).stream_async(client, page_size=500)

asyncio.run(run())
from nocoly_explorer import NocolyFilter

# Single field
f1 = NocolyFilter.quick(Status="Active")

# Multiple fields on the same row (AND)
f2 = NocolyFilter.quick(Status="Active", Region="HK")

# Comparison operators via __suffix
f3 = NocolyFilter.quick(
    _updatedAt__gt="2025-01-01",
    Amount__lte=10000,
    Name__contains="corp",
)

# Combine with AND / OR groups (max depth: 3)
f4 = NocolyFilter.and_group([f1, or_group([f2, f3])])
# Requires the service running:
#   uvicorn nocoly_explorer.service:app --port 8080
#   arq nocoly_explorer.service.worker.WorkerSettings

How a job flows

One HTTP request → enqueued in Redis → Arq worker streams pages → partitioned Parquet.

Caller
n8n / cron / notebook
POST /jobs
→
API
FastAPI
POST /jobs → enqueue
→
Queue
Redis
job_id, status, progress
→
Worker
Arq + AsyncClient
stream_async pages
→
Source
Nocoly
paginated rows
↓
Sink
Partitioned Parquet
region=HK/data_0.parquet · region=SZ/data_0.parquet

Memory stays bounded by row_group_bytes rather than growing with row count. A cancel request flips a flag the worker checks between pages — cooperative cancellation, no orphaned half-written files.

Service API

The FastAPI service orchestrates exports from any scheduler. Authenticate with Authorization: Bearer when set.

MethodPathPurpose
GET/healthzLiveness — always 200
GET/readyz200 if Redis reachable, else 503
POST/jobsSubmit — returns {"job_id": "..."}
GET/jobs/{id}Status + progress + rows_fetched
GET/jobs/{id}/resultArtifact path — 409 if not yet succeeded
POST/jobs/{id}/cancelCooperative cancellation at page boundary

Submit a job

curl -X POST http://localhost:8080/jobs \
  -H "Authorization: Bearer $NOCOLY_SERVICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "host": "https://your-nocoly-host",
    "worksheet_id": "ws_123",
    "page_size": 200,
    "max_pages": 1000,
    "concurrency": 8,
    "output": {
      "sink": "parquet_local",
      "path": "/mnt/datalake/nocoly/ws_123",
      "partition_by": "created_date",
      "partition_granularity": "day"
    }
  }'
# {"job_id": "a1b2c3..."}

Poll status

curl http://localhost:8080/jobs/a1b2c3... \
  -H "Authorization: Bearer $NOCOLY_SERVICE_API_KEY"
# {"job_id":"a1b2c3...","status":"running","progress_pct":42,
#  "rows_fetched":12500,"started_at":"...","finished_at":null}
